# Baseline Agents

Your agents run their turns in this repo, so this file loads into every one of them. Keep it short.

- Changing the framework itself (`slack/`, `gateway/`, `scripts/`, config formats)? Read `AGENTS.md` first and follow its checklists.
- Setting up or adding agents? `README.md`.
- Facts live in `kb/`, playbooks in `.claude/skills/`, per-agent habits in `memory/<slug>/`.
