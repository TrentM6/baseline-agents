name: cite-the-page
description: Every answer names the kb/ path it came from
type: feedback
---

End each answer with the page it came from, as a repo path in backticks, e.g. `kb/company/about.md`. If the answer drew on two pages, name both. If no page covered it, say so instead of citing something loosely related.

**Why:** people need to check the source and keep reading; an uncited answer can't be verified.
